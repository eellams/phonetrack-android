## [0.3.1] – 2026-09-27

A security update.

- **Security:** another app on the phone could open PhoneTrack's certificate dialog with a
  certificate of its choosing. Accepting it would have let that app read the traffic to your
  server. Only PhoneTrack can open the dialog now.
- **Self-signed certificates:** accepting one on the web login page now works; it used to cancel
  the page anyway. Certificates you already accepted stay trusted, and while the app is open the
  certificate dialog appears right away instead of as a notification.
- The app is less than half the size (6.4 MB instead of 14 MB).

## [0.3.0] – 2026-09-27

Targets Android 17 and now requires **Android 14 or newer**: the Android versions that still get
security updates.

### Updating – please read
- **Android 8.0 to 13 are no longer supported.** Those phones stay on
  [0.2.0](https://github.com/lazzurs/phonetrack-android/releases/tag/v0.2.0), which keeps working.
- **Android 17: server on your home network?** If your Nextcloud or PhoneTrack server is reached by
  a local address (a LAN IP such as `192.168.x.x` or a `.local` name), the app now asks for the
  *Nearby devices* permission. Allow it, or it can't reach the server. Servers reached over the
  internet, and logins through the Nextcloud app, don't need it.


### Build and CI

- **Breaking:** Require Android 14 (minSdk 34), the oldest version with security updates ([582d960](https://github.com/lazzurs/phonetrack-android/commit/582d960c1785bf445f62cb405eff262b11696ba2))
- Target Android 17 (targetSdk 37); tests emulate it ([d9687f4](https://github.com/lazzurs/phonetrack-android/commit/d9687f4e73929a4367944fe44da35eea2fe3d33f))

## [0.2.0] – 2026-09-26

First release of the [lazzurs fork](https://github.com/lazzurs/phonetrack-android), brought up to
current Android requirements (targets Android 16 / API 36).

### Updating – please read
- **New app ID: `io.github.lazzurs.phonetrack`.** This fork is now its own app, so it installs
  **next to** the original PhoneTrack (F-Droid / GitLab builds) instead of replacing it. Nothing is
  copied over from the original app: set up your Nextcloud account and logjobs again, then
  uninstall the original once you're happy. The same applies to the earlier `-fork` test builds.
- **SMS commands now need allowed senders.** Settings → Sms → *Allowed senders* (or *Add a sender
  from contacts*). Until at least one number is added, every SMS command is ignored.
- **Passwords are no longer in cloud backups.** After restoring the phone from a backup, enter the
  Nextcloud password (unless you log in through the Nextcloud app) and custom logjob passwords again.
